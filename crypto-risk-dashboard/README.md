# Crypto Risk Dashboard

Mock Web3 risk-operations dashboard for a Binance-style Risk Analyst application.

It demonstrates:

- SQL/Python transaction review
- abnormal activity scoring
- risk typology classification
- Key Risk Indicator summary
- reviewer-friendly dashboard output

Run:

```bash
python3 risk_pipeline.py
open dashboard.html
```

The data is synthetic and contains no real customer or exchange data.
